# A Date With Johra ♡

A romantic, interactive date invitation and planner made by Sami for Johra.

## Features

- Playful proposal screen with an evasive “No” button
- Four-step date, activity, food, and notes planner
- Mobile-first responsive experience
- Animated celebration and date-plan summary
- Clipboard and WhatsApp sharing

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run check
npm run build
```
